# Airlock 3.0 Review Resolution

**Date:** 2026-08-20
**Source review:** `2026-08-20-airlock-3.0-review.md`

## Resolved

| Finding | Resolution | Regression coverage |
|---|---|---|
| R1 | Coordinator state (`airlock.plan.json`, `.airlock/**`) is excluded from product boundaries; `init` stages created state. | `init state does not poison the first task boundary` |
| R2 | Blocking a doing task preserves its product delta under `refs/airlock/blocked/...`. | `blocking a failed task preserves its delta and releases the next task` |
| R3 | A failed task commit restores the exact previous plan content and unstages its plan path, leaving the task retryable. | `failed task commit restores the doing state` |
| R4 | Claude uses `${CLAUDE_PLUGIN_ROOT}`; OpenCode invokes the installed `airlock` bin. | Shim assertions and README installation instructions |
| R5/R10 | Checker lookup anchors and escapes the task trailer, then emits only owned product paths; truncation is explicit. | `checker uses the exact dependency trailer and excludes plan churn` |
| R6 | Scope recovery creates retained `refs/airlock/reverted/...` stash commits instead of deleting untracked paths. | `audit recovery stashes untracked paths instead of deleting them` |
| R7 | `ask --blocking --case goal` supports plan-level decisions with no blocked task. | `goal-level blocking decisions do not require a task` |
| R8 | `maxExpensive` caps host-critical tasks plan-wide and emits `BUDGET REACHED`. | `critical-model budget parks expensive work while allowing cheap work` |
| R9 | Both shims expose and forward `--unattended`; blocking decisions return `PARKED`. | `unattended next parks blocking decisions without dispatching` |
| R11 | Model configuration maps each OpenCode role/model pair to an exact agent name emitted in the brief. | `OpenCode briefs name the exact configured agent` |
| R12 | Static disjoint glob prefixes may run in parallel; ambiguous patterns remain serialized. | `parallel tasks with disjoint glob prefixes may start together` |
