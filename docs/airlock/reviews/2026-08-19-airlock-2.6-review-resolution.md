# Airlock 2.6 Review Resolution

**Date:** 2026-08-19
**Source review:** `2026-08-19-airlock-2.6-review.md`

## Resolved Before Release

- **R1:** `single-actor` contracts apply worker scope without requiring a resolved OpenCode parent session.
- **R2:** the adapter selects `Bash` or `PowerShell` from the configured shell rather than the host OS; Windows PowerShell, Windows Git Bash, and POSIX shell mappings are tested.
- **R3:** `hooks/contract-v2.mjs` is the single source for v2 validity and expiry checks. The adapter parity test proves malformed contracts remain inactive and fail open.
- **R4:** session details are memoized by session ID and guard input evaluation stops at the first denial. A multi-file allow path still evaluates each path independently to preserve canonical guard semantics.
- **R5:** the adapter README and 2.6 specification document ledger-patch, runtime-failure, and exact-tool-coverage divergences.

## Post-Pull Gate

- **Windows child session:** status plus allowed and denied PowerShell root-session canaries passed. The worker dispatch did not return before its bounded CLI timeout, so it is not release evidence.
- **R6 Linux:** after pulling this branch on Linux, run `node --test scripts/opencode-guard.test.mjs`, then run an active-contract OpenCode canary with `/bin/bash`: verify status, owned-path allow, out-of-scope deny, and worker `task` deny. Record the results before a 2.6.1 release.
